# SabaqLoop

[Открыть приложение](https://wpalish.github.io/sabaqloop/) · [Возможности и ограничения](https://wpalish.github.io/sabaqloop/about.html)

Учебная практика из собственного материала: вопросы с источником, проверка преподавателем, ответы с объяснением, история версий и повторение ошибок. Это самостоятельный репозиторий продукта. Он выделен из Startup Lab KZ с сохранением истории исходного кода.

## Запуск

Нужны Node.js 22+ для тестов и Python 3 для локального HTTP-сервера. Внешних npm-зависимостей нет.

```sh
npm test
npm start
```

Открыть `http://127.0.0.1:8780/`. Все файлы сайта находятся в `dist/`; GitHub Actions запускает тесты и размещает эту папку на GitHub Pages.

## Возможности версии 0.1

- Наборы материалов RU, KK, EN или mixed; интерфейс на русском.
- Задания с коротким ответом или выбором одного варианта.
- Название источника и подтверждающий фрагмент обязательны.
- Черновики с пропуском слова из собственного текста. Это правила обработки текста, без нейросети.
- Одобрение перед практикой. Изменение создаёт новую версию и снова требует проверки.
- Верный ответ, объяснение и источник после попытки. История хранит исходный снимок задания.
- Повторение ошибки сразу; после верного ответа — через 1, 3, 7, 14 и 30 дней.
- Проверяемые JSON-копии, предварительный просмотр перед восстановлением, сохранение предыдущей копии.
- Отказ от перезаписи при обнаружении изменений в другой вкладке; повреждённая копия не сбрасывается молча.

## Границы

Это локальный браузерный инструмент, а не облачная система управления классом. Один браузер — одна рабочая область. Нет отдельных защищённых аккаунтов, групп, серверного журнала, синхронизации, оплаты, контроля экзамена или оценивания IELTS. Не хранить персональные данные учеников. Регулярно экспортировать копию: браузер может удалить localStorage.

Короткий ответ сравнивается с правильным ответом и явными допустимыми вариантами. Проверки по смыслу нет. Три оригинальных демонстрационных вопроса по английскому не являются официальным IELTS-тестом. Эффективность расписания и результаты обучения отдельно не исследованы.

В приложении нет аналитики и внешних AI-запросов. Хостинг обслуживает запросы к страницам. Внешние источники открываются только по нажатию пользователя.
